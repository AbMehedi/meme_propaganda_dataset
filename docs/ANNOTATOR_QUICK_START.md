# Annotator quick start

**Do three things: mark evidence → explain each mark → finish and Submit.**

In **Stage A**, read only the caption and copied image text. Keep the image closed.
In **Stage B**, review the full post afresh, including its picture.

## 1. Mark the evidence

Read the post. Click a technique button above the relevant text, then drag across
the smallest phrase that supports it. Open **Technique guide** if you need a definition.

In Stage B, you can also choose a technique above the picture and draw a box around
the supporting picture detail. Printed words are text evidence: highlight those words
in the copied text. A face or flag alone does not prove a persuasion technique.

If two techniques use the same phrase, create two labeled highlights and explain
each separately. To remove a mistaken mark, select it and use the trash icon.

## 2. Explain each mark

**Click the highlighted words or picture box.** You can also select the mark in the
Regions list. The panel titled **Explain the selected mark** shows its questions.
On a narrow screen, the panel sits below the source material.

| Field | What to enter |
| --- | --- |
| Why does this evidence fit the technique? | One sentence linking this evidence to the definition. Bangla or English is fine. |
| How sure are you? | 3 = clear evidence; 2 = borderline but supported; 1 = unsure. |
| Claim number | Usually `1`. Use `2` only for a separate claim of the **same** technique. |
| Who or what is targeted? | The named person or group. Leave blank if unknown. |

For example, the first T01 claim and first T03 claim both use `1`. Two related
marks supporting one T03 claim also both use `1`. The number displayed beside a
mark in the Regions list is its display order; enter the claim number in the form.

**Type directly into the fields. There is no Add step.** Answers are kept when you
select another mark and saved with the task when you press Submit. Complete the
questions for **every** mark, including any mark created by mistake that you keep.

Stage B also asks how the picture helps and whether words alone are enough:

| Picture's role | Words alone enough? | Evidence needed |
| --- | --- | --- |
| Not used | Yes | Text highlights |
| Adds support | Yes | Text highlights and picture boxes |
| Needed | No | Picture boxes; text highlights if relevant |
| Needs review / unsure | Your best supported answer, or Unsure | Explain the uncertainty |

Related marks for the same technique and claim number must use the same picture-role
and words-alone answers. For a picture box, also choose picture content versus text
appearance, and a specific area versus the whole picture. A whole-picture box must
cover the complete image.

## 3. Finish and Submit

1. Tick the techniques used in your marks. Highlighting does **not** tick this list.
2. If a complete review finds no supported technique, select **No technique** and
   leave technique boxes and evidence marks empty. Do not use this for uncertainty.
3. Choose **Complete**, **Needs review**, or **Exclude**.
4. Write a short **Final note** explaining your decision or what needs checking.
5. Press Label Studio's **Submit** button.

Problems and additional techniques are under **Optional: report a problem or another
technique**. Describe them in the final note. Model-assisted tasks also ask whether
you accepted, changed, or rejected the suggestion, or had no suggestion available.

If Submit reports a missing answer, read the field name in the message. For a mark,
return to Step 2 and complete the selected mark's questions. For status or final
note, return to Step 3. If the evidence panel still does not appear after selecting
a mark, contact the coordinator: that is a form problem, not an annotation decision.

The coordinator validates exports before review. Label Studio checks required fields;
the exporter also checks exact quotations, picture coordinates, linked marks, and
whether selected techniques have supporting evidence.
